# Security Policy

This repository contains personal Arch Linux setup instructions and scripts. It is **not** a supported or audited installer. Review each command before running it, especially commands using root privileges, package signing keys, third-party repositories, remote installers, disk partitioning or encryption.

## Reporting a vulnerability

Please **do not publish credentials, tokens, private keys or exploit details in public issues**. Use GitHub's private vulnerability reporting feature if enabled for this repository. If it is unavailable, contact the repository maintainer through a private channel before disclosing details publicly.

## Supported versions

No stable or supported releases are currently designated. The default branch may contain outdated or untested instructions. Treat all scripts as examples until validated on an isolated test system.

## Third-party downloads

Download vendor software from official upstream sources and review applicable license terms. Never rely on binaries committed to this repository as trusted installation sources.
